# 🚗 Auto Care — Sistema Web de Gestão Automotiva

O Auto Care é uma plataforma web desenvolvida com o objetivo de simplificar o acompanhamento e o controle de manutenção, abastecimento, documentos e despesas veiculares. O sistema permite que proprietários de veículos tenham uma visão clara e organizada de toda a vida útil e custos associados aos seus automóveis.

## 🎯 Objetivo do Projeto

Este projeto foi desenvolvido com o propósito de aplicar e consolidar os conhecimentos práticos de HTML, CSS e Java adquiridos durante a disciplina.

Por meio de uma aplicação funcional e orientada ao domínio real de gestão veicular, foram trabalhados conceitos de:

. Estruturação semântica de páginas web;

. Estilização responsiva e design intuitivo de interface;

. Lógica de programação orientada a objetos no backend;

. Manipulação e persistência de dados no contexto de um sistema web.

## Páginas

O projeto possui 8 páginas:

- Página inicial
- Cadastro
- Login
- Despesas
- Veiculo
- Documentos
- Manutenções
- Registro manutenção


## Estrutura 

- `Paginas/` — Páginas do sistema
- `img/` — Imagens
- `Codigo_CSS/` — Página de CSS
- `script.js/` — Página de Java

## 🛠️ Tecnologias Utilizadas

. HTML: Estruturação semântica das páginas web da plataforma.

. CSS: Estilização visual, layout responsivo e padronização da identidade visual.

. Java: Desenvolvimento da lógica de negócios backend, manipulação das entidades e integração com a camada de persistência.
